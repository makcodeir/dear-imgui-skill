# Dear ImGui Agent Skill

> این یک اسکیلی هست که توی تابستون ۱۴۰۵ ساختمش. ۹۹ درصدش رو هوش مصنوعی تولید کرده. حجم زیادی توکن رو خرج کردم و GUI های مختلفی رو مهندسی معکوس کردم تا این اسکیل رو اوکی کنم.  
> نکته جالب اینه که هیچ آشنایی با این کتابخانه نداشتم ولی به کمک SKILL EVAL و آشنایی با ذات GUI می دونستم که یک ایجنت چه چالش هایی برای طراحی یک GUI داره.

---

## ⚙️ ویژگی‌ها و قابلیت‌های اسکیل

* **راه‌اندازی تا خروجی تصویر:** در این اسکیل از نصب imgui از گیت هاب تا اسکریپت هایی برای گرفتن تصویر توسط ایجنت طراحی شده.
* **تست نرم‌افزار:** همچنین ایجنت با این اسکیل قادر هست تا یک API برای تست بخش های نرم افزار طراحی شده تولید کنه.
* **اسکریپت‌های آماده:** همچنین این اسکیل حاوی اسکریپت هایی هست که ایجنت رو از نوشتن مجدد آن بی نیاز میکنه.
* **ثبت خطاها حین ساخت:** در طی طراحی این اسکیل ، مدل باگ هایی که بهش برخورد میکرده رو داخل اسکیل لحاظ میکرده.
* **کاهش سرچ و دیباگ:** با اینکه حجم این اسکیل خیلی زیاد هست ولی حاوی نکات و راهنمایی هایی هست که ایجنت رو از سرچ در اینترنت و یا دیباگ های سنگین و بی مورد بی نیاز میکنه.
* **بهره‌وری بالا:** خروجی نهایی با کیفیت تر و کم هزینه تر تولید میشه.
